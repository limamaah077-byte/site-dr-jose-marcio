# Site — Dr. José Marcio Issa

Site estático pronto para publicação no GitHub Pages.

## Publicar
1. Crie um repositório público no GitHub.
2. Envie `index.html` e `favicon.svg` para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.

O GitHub exibirá o endereço público do site na própria tela do Pages.
